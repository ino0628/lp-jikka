結論

実家じまいとは、相続した実家を最終的に手放す（売る・貸す・壊す）までの一連の手続きのことです。費用の主な項目は4つ。片付け（業者に頼むと3LDK以上の一軒家で50万〜100万円以上、1R・1Kなら10万〜15万円）、解体（木造30坪で90万〜200万円が事業者の公表相場・必要な場合だけ）、相続登記（登録免許税は固定資産税評価額の0.4%）、売却の仲介手数料（上限は売買価格の3%＋6万円＋税、800万円以下の物件は最大33万円税込）。買取なら片付け費用も仲介手数料もかからないことが多く、同じ家でも頼み方で手取り（税引き前）が数十万〜100万円以上変わります。順番は「家財そのままで査定 → 3つの出口を手取りで比べる → 必要な分だけ片付け・解体 → 相続登記 → 引き渡し」。期限は相続登記が3年以内、空き家の3,000万円特別控除が相続開始から3年を経過する日の属する年の12月31日までです。

「実家じまい」という言葉を検索して、いくらかかるのか、何から始めるのか、を知りたい方向けに、全体像を1枚にまとめます。細かい話は個別の記事に譲り、ここでは費用の項目・順番・期限の3つだけを押さえます。

実家じまいとは何か

相続した（または相続する予定の）実家を、最終的に手放すまでの一連の手続きです。出口は3つしかありません。売る・貸す・壊す。このうち「貸す」は買い手ではなく借り手を探す話なので、実家じまいの相談の大半は「売る」と「壊す」、そしてその前の「片付ける」に集まります。

つまり実家じまいの費用とは、片付け・解体・登記・売却にかかる費用の合計です。

見てのとおり、片付けと解体と仲介手数料は「出口の選び方」で0円にもなる費用です。だから実家じまいの費用は、最初から「いくら」と決まっているものではなく、順番で決まります。

ここまでの目安で、いちど見積を取ってみますか。

無料で査定と見積を手配する

紹介は無料・入力1分・断っても費用はかかりません

同じ家でも頼み方で手取りが変わる

例として、3LDKの実家で買取1,200万円の提示があった場合を並べます。ここでの手取りは、売却額から費用を引いた税引き前の額です。

  • 片付けてから仲介で売る：遺品整理70万円を先払い。1,500万円で売れたとして仲介手数料は上限56.1万円。手取り約1,374万円。売れるまで数か月かかり、その間の固定資産税と管理は続く。
  • 家財ごと買取：買取額1,200万円、片付け0円、手数料0円。手取り1,200万円。数週間で完了。

差は約174万円ですが、前者は「1,500万円で売れる」前提つきで、片付け費用は売れなくても戻りません。傷みが進んでいる家、遠方で管理できない家ほど、後者の確実さが効きます。

損しない順番

損しない順番

  1. 1
    家財そのままで査定と見積
    名義が親のままでも取れる
  2. 2
    3つの出口を手取りで比べる
    買取・仲介・解体して土地で売る
  3. 3
    必要な分だけ片付け・解体
    買取なら片付け不要
  4. 4
    相続登記
    売る相手と条件が見えてから、決済までに
  5. 5
    売却・引き渡し
  1. 家財そのままで査定と見積を取る。名義が親のままでも取れます。
  2. 買取・仲介・解体して土地で売る、の3つを手取りで比べる。
  3. 必要な分だけ片付け・解体する。買取なら片付け不要。解体は、解体後の手取りが現状買取を上回るときだけ。
  4. 相続登記。売る相手と条件が見えてから、決済までに。
  5. 売却・引き渡し。

やってはいけないのは3つ。片付けてから査定する（家財ごと引き取る会社を選べなくなる）。相続人の話し合いより先に解体を決める。そして、比べずに解体してから売る（1月1日をまたぐと固定資産税の住宅用地の特例が外れます）。ただし耐震基準を満たさない家屋は、3,000万円控除を使うために取り壊しが要る場合があります。壊すかどうかは手取りで比べてください。

期限のある制度が2つ

制度 期限 過ぎると
相続登記の義務 相続で不動産を取得したと知った日から3年以内（2024年4月1日より前に相続したことを知った不動産は2027年3月31日まで） 10万円以下の過料の対象
空き家の3,000万円特別控除（その家を取得した相続人が3人以上なら1人2,000万円・売却代金1億円以下・家屋が耐震基準を満たすか取り壊して売ることが条件） 相続開始から3年を経過する日の属する年の12月31日まで（制度は2027年12月31日まで） 売却益に約20%の税金（所有期間5年超の場合。相続では親の所有期間を引き継ぐ）

例えば2024年6月に相続した実家なら、控除の期限は2027年12月31日、登記の期限は2027年6月。逆算すると、2027年の春には売り方が決まっていないと間に合いません。

まとめ

  • 実家じまいの費用は、片付け・解体・登記・仲介手数料の4項目。前3つは出口の選び方で0円にもなる
  • 順番は「家財そのままで査定 → 出口を手取りで比べる → 必要な分だけ片付け・解体 → 登記 → 引き渡し」
  • 期限は相続登記3年・3,000万円控除は相続開始から3年を経過する日の属する年の12月31日。逆算して春までに売り方を決める

実家じまい案内所は、不動産の売買の仲介・解体の施工・登記や申請の代行・税務相談を行いません。実家のある地域で対応できる会社を最大3社まで手配し、家財そのままの査定額と、買取・仲介・解体それぞれの見積を1枚に並べます。しつこい営業はしないよう、対応する会社と取り決めています。税額の計算は税理士に、登記は司法書士にご確認ください。

よくある質問

実家じまいはどこから手をつければいいですか

片付けでも登記でもなく、家財そのままで査定を取ることからです。売れる額が分かると、片付けにいくらかけていいか、解体する価値があるか、兄弟にどう説明するかが決まります。

全部でいくらかかりますか

出口で変わります。家財ごと買い取ってもらう形なら片付け費用も仲介手数料もかからず、登記の登録免許税だけで済むことがあります。片付けてから仲介で売る形なら、片付け数十万円と手数料が先に出ます。

期限はありますか

相続登記は、相続で不動産を取得したと知った日から3年以内（2024年4月1日から義務・10万円以下の過料。それより前に相続したことを知った不動産は2027年3月31日まで）。空き家の3,000万円特別控除を使うなら、相続開始から3年を経過する日の属する年の12月31日まで、かつ2027年12月31日までの売却です。
